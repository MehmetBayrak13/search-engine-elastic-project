# Streamlit's bundled GZip middleware (streamlit/web/server/starlette/starlette_gzip_middleware.py)
# calls GZipResponder() without the `thread_minimum_size` kwarg that Starlette made
# mandatory in 1.4.0, so any Starlette >=1.4.0 breaks Streamlit's server on startup
# with "GZipResponder.__init__() missing 1 required keyword-only argument:
# 'thread_minimum_size'". Streamlit's own dependency range (starlette<2,>=0.46.0 as of
# streamlit 1.61.0) does not exclude 1.4.0, so pin below it explicitly until Streamlit
# ships a fix. Verified working with Starlette 1.3.1.
starlette>=0.46.0,<1.4.0
